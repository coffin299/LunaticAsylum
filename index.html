LunaticAsylum

ゲームサーバー管理デスクトップアプリ。ZIP を展開して exe を起動し、隣の Servers にフォルダを置くだけ。

Download GitHub

使い方（要約）

1. Release のポータブル ZIP を展開
2. LunaticAsylum.exe を起動
3. Servers に任意名フォルダでサーバーを配置（または SteamCMD インストール）

Unzip the portable build, run LunaticAsylum.exe, and place freely named server folders under Servers.
